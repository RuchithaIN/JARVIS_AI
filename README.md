# JARVIS_AI
python-based personal AI voice assistant
JARVIS AI – Personal Voice Assistant

A Python-based personal voice assistant that listens to voice commands and helps perform tasks on a computer.

Features

- Voice recognition and speech responses
- Wake-word activation using "Jarvis"
- Opens websites and performs supported computer tasks
- System information monitoring
- Volume control
- Time and date responses

Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- PyAudio
- psutil
- PyAutoGUI
- pycaw

Requirements

- Python installed on your computer
- A working microphone
- Internet access for features that require it

Installation

1. Clone or download this repository.

2. Open the project folder in a terminal.

3. Create a virtual environment:
   
   "py -m venv .venv"

4. Activate it on Windows:
   
   ".venv\Scripts\activate"

5. Install dependencies:
   
   "py -m pip install -r requirements.txt"

Run the Project

Run the following command in the activated environment:

"python main.py"

Allow microphone access if prompted.

Project Purpose

This project was developed to learn Python, speech recognition, text-to-speech, and desktop automation.
